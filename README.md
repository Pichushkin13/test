# Beautiful Calculator (Windows GUI)

Это полноценное GUI-приложение-калькулятор в стиле Windows (базовые функции: `+`, `-`, `*`, `/`, `%`, `+/-`, `.`).

## Что оставлено в репозитории

Только необходимое для сборки EXE через GitHub:
- `calculator_gui.py` — исходник GUI-приложения.
- `.github/workflows/build-windows-exe.yml` — автоматическая сборка EXE.

## Как получить готовый EXE

1. Откройте репозиторий на GitHub.
2. Вкладка **Actions**.
3. Запустите workflow **Build Windows Calculator EXE**.
4. После завершения скачайте artifact `BeautifulCalculator-exe`.
5. Запустите `BeautifulCalculator.exe` на Windows.
